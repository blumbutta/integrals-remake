# Integrals: Remake

Самостоятельный ремейк idle-кликера про интегралы с исходным синим оформлением и изображениями покупок. Интерфейс на русском: 11 генераторов, 86 исследований, 120 достижений, 20 наградных тем и отдельный облик каждого перерождения.

Ручной клик приносит прежнюю силу клика плюс 5% текущего производства в секунду. Пять исследований поднимают эту долю до 20%. Новые производственные исследования открываются при 50, 75, 100 и 150 помощниках. Отдельное исследование командной работы позволяет ранним ресурсам усиливать всю лабораторию: 50 помощников дают +6,7% базового производства, 100 — +10%; дальнейший рост замедляется с пределом +20% на категорию. Вклады команд складываются без повторного усиления самого себя. Базовая окупаемость поздних ресурсов сокращена с 10–12 часов до 20–25 минут; цены покупок и накопленные балансы сохранены.

Золотой интеграл медленно летает поверх игры; его можно поймать кликом. Добавлены оригинальная музыка с отдельной громкостью и 12 добровольных испытаний. Все задания находятся на карте: у открытых зданий видны доступные испытания и заметные отметки. Отдельной вкладки событий нет. Закрытые районы не раскрывают названия, изображения помощников или связанные события. Карта занимает всю вкладку «Мир» без кнопок запуска и раскрытия.

Задания включают арифметику, производные, поиск ошибок, двоичный код, интегралы, закономерности, восстановление входного числа по цепочке операций, хронологию и логику. «Обратный сигнал» показывает все три цепочки постоянно и даёт 75 секунд; двоичный код — 90 секунд. Правила, время, награда и такой же штраф показываются до старта. Ставки фиксируются при запуске; штраф не делает баланс отрицательным. Ранее начатые задания сохраняют условия до завершения.

Чёрная дыра — открытая строка покупки в общем списке «Ресурсы», цена 999 999 999 999 999 интегралов на текущем балансе. После двух подтверждений она переводит игрока на карту, поглощает здания и жителей под отдельную композицию и начинает новую эпоху. Звук можно выключить, а анимацию завершить досрочно; при уменьшенном движении переход короткий. Баланс, помощники и исследования обнуляются, престиж, достижения и рекорды остаются.

На компьютере игра занимает экран: левая колонка с интегралом, центральная область и правый список ресурсов прокручиваются независимо. В каждой категории жители стоят одной строкой. Статистика постоянно закреплена у нижней границы экрана; под ней закреплены авторы оригиналов. На узких экранах действует адаптивная компоновка. Достижения разделены на полученные и закрытые, темы находятся во вкладке «Награды». Купленные исследования идут после неизученных. Числа выводятся полностью, без сокращения до тысяч и миллионов; правило офлайн-производства описано в «Как играть».

Игра: https://blumbutta.github.io/integrals-remake/

Оригинальная версия с интегралами — [rmbk](https://rmbk.me/math-clicker/). Создатель Cookie Clicker — [Orteil](https://orteil.dashnet.org/cookieclicker/). Код и оформление этой игры написаны заново. Изображение «Сверхразума ИИ» предоставлено пользователем. По просьбе пользователя сохранены оригинальные изображения покупок; их авторство относится к оригинальной игре (rmbk / Orteil), а не к этому ремейку. Проект не связан с авторами оригиналов.

## Запуск

Требуется Node 24, внешних зависимостей нет.

```sh
npm run dev
npm test
```

Локальная игра откроется на `http://127.0.0.1:4180/`. Локальная база SQLite находится в `.data/` и не публикуется. GitHub Actions разворачивает только HTML, CSS, JS и графику; сервер и данные не входят в Pages.

## Прогресс и рейтинг

При первом входе поле имени пустое: игрок вводит имя из 2–24 символов и выбирает эмодзи. Облачный сервер проверяет уникальность имени без учёта регистра и лишних пробелов; занятое имя нельзя использовать для нового профиля или переименования. Вход в облако выполняется автоматически по сохранённому в браузере ключу; кнопка «Скачать ключ входа» сохраняет его для другого устройства или восстановления после очистки браузера. Имя и эмодзи публичны и не заменяют ключ. Рейтинг показывает место, эмодзи, имя, интегралы за всё время, текущий баланс и престиж. Первые три места выделены золотой, серебряной и бронзовой рамками.

Каждый тип жителей получает свой интерьер. Автоклики показаны только вокруг интеграла: максимум 100 значков в одном кольце. После 100 применяются цвета с весами 1, 50, 2 500 и далее по 50; при необходимости ×N группирует одинаковый цвет без потери количества. Неоткрытые ресурсы отображаются силуэтом и «???» до достижения базовой цены в заработке за всё время. При наведении или фокусе на ресурсе подсказка показывает его производство и открытые исследования.

После ввода свободного имени при доступном API новая лаборатория получает серверное сохранение и случайный код восстановления. Сохраните код в профиле — он позволяет открыть лабораторию на другом устройстве. Код является секретом доступа: не публикуйте его или экспорт облачного сохранения. Сервер хранит только хеш кода. В рейтинге отображаются игровой ник, накопленный результат и престиж. Участие отключается в профиле.

Если облако недоступно при первом входе, после ввода имени можно выбрать локальную лабораторию с автоматическим сохранением, экспортом и импортом. Уникальность имени проверяется при будущем подключении облака. Локальный результат не переносится в общий рейтинг: клиентские данные невозможно надёжно проверить. Подключение облачной лаборатории явно предлагает начать с нуля и скачать резервную копию локального прогресса. При временном обрыве уже подключённого облака подтверждённый прогресс остаётся на сервере, а очередь неподтверждённых действий повторяется с теми же идентификаторами. Ручные действия старше 15 минут не повторяются; офлайн-производство рассчитывается отдельно. Одновременно редактирует лабораторию одна вкладка: остальные открываются для просмотра.

Клиент передаёт только игровые действия. Сервер рассчитывает доход и стоимость покупок, проверяет доступность исследований и престижа, ограничивает клики и не принимает баланс от клиента. Это защита от прямой подмены баланса, а не гарантия отсутствия автоматизированной игры. Доход при отсутствии активности более 30 секунд начисляется с эффективностью 50%, максимум за 12 часов. Первые 30 секунд после активности считаются в обычном темпе.

При переходе на экономику версии 2 незакрытый интервал старого сохранения один раз начисляется по прежним скоростям. Последующее производство работает по новым правилам. Баланс, покупки, ключ входа и ранее полученные награды сохраняются.

## Производственный сервер

API размещается на существующем общем сервере `https://kozlogon-server.onrender.com/integrals-api/`. Настройка и описание API — в `server/README.md`.

Постоянное хранение требует постоянного диска и переменной `INTEGRALS_DB_PATH`. При отсутствии настройки API возвращает 503, чтобы не обещать сохранение на временном файловом диске. Основной сервер и другие игры продолжают работать. Render по умолчанию не сохраняет файловые изменения между перезапусками.

Пример для диска, подключённого в `/var/data/integrals`:

```text
INTEGRALS_DB_PATH=/var/data/integrals/game.sqlite
```

Подключение платного диска делается отдельно в Render. Резервные копии БД должны включать согласованный снимок SQLite (используйте SQLite backup API либо снимок остановленной БД с корректным checkpoint).

## Управление

Клик по интегралу или пробел — ручное производство. Раздел «Ресурсы» поддерживает ×1, ×10 и MAX (до 100 за операцию). Звук выключен по умолчанию. Интерфейс учитывает уменьшение анимации в системных настройках.
