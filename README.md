# Integrals: Remake

Самостоятельный ремейк idle-кликера про интегралы с сохранением исходного синего оформления и изображений покупок. Интерфейс на русском, мобильная версия, одиннадцать генераторов, 26 исследований, золотые интегралы, 91 достижение, восемь наградных оформлений и престиж.

Добавлены оригинальная фоновая музыка с отдельной громкостью и девять добровольных испытаний: арифметика, производные, поиск ошибок, двоичный код, интегралы, закономерности, память, хронология и логика. Этап открывается после покупки соответствующего помощника. Награда, штраф и лимит времени показаны до старта.

Карта занимает всю доступную область вкладки «Мир интегралов» без рамки и кнопок запуска или разворачивания. В ней открываются школа, университет, вычислительный квартал, портальные острова, обсерватория времени и космическая башня. Здания и жители доступны для осмотра. После «Глубокой мысли» открывается «Сверхразум ИИ» за 10 000 000 000 000 интегралов: 240 000 000 ∫/с до улучшений, два собственных исследования и орбитальное ядро с изображением пользователя. Кроме девяти обычных испытаний, в мире есть школьная олимпиада, метеорный поток и академическое открытие. Двоичный код даёт 90 секунд. Все задания добровольные, с правилами и ценой ошибки до старта. В новых испытаниях награда и штраф одинаковы: максимум из награды за клики и 30 секунд текущего производства. Сумма фиксируется при старте; штраф не создаёт отрицательный баланс. Уже начатые испытания сохраняют прежние условия до завершения.

Чёрная дыра находится в разделе «Ресурсы» и стоит 999 999 999 999 999 интегралов на текущем балансе. Она переводит игрока в мир и требует двух подтверждений. Затем чёрная дыра поглощает здания и жителей, звучит отдельная синтезированная композиция, рождается новая эпоха. Звук можно выключить, а анимацию завершить досрочно; при уменьшенном движении переход короткий. Полный баланс, помощники и исследования обнуляются; престиж, достижения и рекорды остаются. Каждый цикл открывает свой облик.

Достижения разделены на полученные и закрытые; оформления находятся во вкладке «Награды». На главной странице каждая категория жителей показана одной строкой; внутренней прокрутки нет. Статистика всегда открыта и закреплена внизу экрана. Купленные исследования расположены после неизученных. Правило офлайн-производства описано в «Как играть». Вокруг интеграла не более 100 курсоров в одном кольце, с уменьшением размера при росте количества. Каждый ручной клик перезапускает короткую встряску; автопроизводство её не вызывает. Числа отображаются полностью. Исходная синяя тема и оригинальные рисунки сохранены.

Игра: https://blumbutta.github.io/integrals-remake/

Оригинальная версия с интегралами — [rmbk](https://rmbk.me/math-clicker/). Создатель Cookie Clicker — [Orteil](https://orteil.dashnet.org/cookieclicker/). Код и оформление этой игры написаны заново. Изображение «Сверхразума ИИ» предоставлено пользователем. По просьбе пользователя сохранены оригинальные изображения покупок; их авторство относится к оригинальной игре (rmbk / Orteil), а не к этому ремейку. Проект не связан с авторами оригиналов.

## Запуск

Требуется Node 24, внешних зависимостей нет.

```sh
npm run dev
npm test
```

Локальная игра откроется на `http://127.0.0.1:4180/`. Локальная база SQLite находится в `.data/` и не публикуется. GitHub Actions разворачивает только HTML, CSS, JS и графику; сервер и данные не входят в Pages.

## Прогресс и рейтинг

В профиле можно выбрать эмодзи. Вход в облако выполняется автоматически по сохранённому в браузере ключу; кнопка «Скачать ключ входа» сохраняет его для другого устройства или восстановления после очистки браузера. Имя и эмодзи публичны и не заменяют ключ. Рейтинг показывает место, эмодзи, имя, интегралы за всё время, текущий баланс и престиж. Первые три места выделены золотой, серебряной и бронзовой рамками.

Каждый тип жителей получает свой интерьер. Автоклики показаны только вокруг интеграла: максимум 100 значков в одном кольце. После 100 применяются цвета с весами 1, 50, 2 500 и далее по 50; при необходимости ×N группирует одинаковый цвет без потери количества. Неоткрытые ресурсы отображаются силуэтом и «???» до достижения базовой цены в заработке за всё время. При наведении или фокусе на ресурсе подсказка показывает его производство и открытые исследования.

При доступном API новая лаборатория получает серверное сохранение и случайный код восстановления. Сохраните код в профиле — он позволяет открыть лабораторию на другом устройстве. Код является секретом доступа: не публикуйте его или экспорт облачного сохранения. Сервер хранит только хеш кода. В рейтинге отображаются игровой ник, накопленный результат и престиж. Участие отключается в профиле.

При первом запуске без доступного API работает локальная лаборатория с автоматическим сохранением, экспортом и импортом. Её результат не переносится в общий рейтинг: клиентские данные невозможно надёжно проверить. Подключение облачной лаборатории явно предлагает начать с нуля и скачать резервную копию локального прогресса. При временном обрыве уже подключённого облака подтверждённый прогресс остаётся на сервере, а очередь неподтверждённых действий повторяется с теми же идентификаторами. Ручные действия старше 15 минут не повторяются; офлайн-производство рассчитывается отдельно. Одновременно редактирует лабораторию одна вкладка: остальные открываются для просмотра.

Клиент передаёт только игровые действия. Сервер рассчитывает доход и стоимость покупок, проверяет доступность исследований и престижа, ограничивает клики и не принимает баланс от клиента. Это защита от прямой подмены баланса, а не гарантия отсутствия автоматизированной игры. Доход при отсутствии активности более 30 секунд начисляется с эффективностью 50%, максимум за 12 часов. Первые 30 секунд после активности считаются в обычном темпе.

## Производственный сервер

API размещается на существующем общем сервере `https://kozlogon-server.onrender.com/integrals-api/`. Настройка и описание API — в `server/README.md`.

Постоянное хранение требует постоянного диска и переменной `INTEGRALS_DB_PATH`. При отсутствии настройки API возвращает 503, чтобы не обещать сохранение на временном файловом диске. Основной сервер и другие игры продолжают работать. Render по умолчанию не сохраняет файловые изменения между перезапусками.

Пример для диска, подключённого в `/var/data/integrals`:

```text
INTEGRALS_DB_PATH=/var/data/integrals/game.sqlite
```

Подключение платного диска делается отдельно в Render. Резервные копии БД должны включать согласованный снимок SQLite (используйте SQLite backup API либо снимок остановленной БД с корректным checkpoint).

## Управление

Клик по интегралу или пробел — ручное производство. Раздел «Ресурсы» поддерживает ×1, ×10 и MAX (до 100 за операцию). Звук выключен по умолчанию. Интерфейс учитывает уменьшение анимации в системных настройках.
